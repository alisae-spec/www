# 📄 Product Requirements Document (PRD)
## 프로젝트명: 스토리뱅크 AI자소서 메이커

---

### 1. 프로젝트 개요
| 항목 | 내용 |
| :--- | :--- |
| **프로젝트 이름** | **스토리뱅크 AI자소서 메이커** |
| **한 줄 설명** | 지원 정보와 STAR 경험 스토리를 바탕으로 맞춤형 자기소개서를 1분 만에 생성하고 다운로드하는 AI 웹 서비스 |
| **유형** | 반응형 웹 서비스 (PC / 모바일 겸용) |
| **난이도** | 중급 (바이브코딩 기반의 빠른 프로토타이핑 및 AI API 연동) |

---

### 2. 사용자 시나리오
* **Target User (누가):** 채용공고에 맞춰 다수의 자기소개서를 빠르게 작성해야 하는 취업준비생 및 이직 희망자
* **Situation (언제):** 서류 마감 직전에 효율적으로 자소서를 작성해야 할 때, 또는 자신의 경험(STAR)을 특정 직무 공고에 맞춰 구조화하기 어려울 때
* **Goal / Pain Point (왜):** 경험 정리부터 직무 맞춤형 자소서 작성, 항목별 글자 수 맞춤, 완성된 문서 다운로드까지 한곳에서 빠르게 끝내어 서류 작성 시간을 획기적으로 줄이기 위해

---

### 3. 핵심 기능 목록 (필수 기능)
1. **지원 정보 입력:** 지원 회사명 및 목표 직무 입력
2. **채용공고 입력/업로드:** 공고 텍스트 직접 입력 또는 공고 파일(PDF/TXT) 업로드 및 텍스트 파싱
3. **경험 입력 (유연한 입력 방식):** STAR 구조(Situation, Task, Action, Result) 폼 입력 또는 이력서/경력기술서 파일 업로드 (둘 중 하나만 선택/입력해도 진행 가능)
4. **항목별 분할 생성:** 지원동기, 직무 역량, 성격의 장단점, 문제해결 경험 등 자소서 문항별 선택 및 맞춤 생성
5. **실시간 글자 수 세기 & 맞춤 조절:** 생성된 자소서의 공백 포함/제외 글자 수 실시간 측정 및 AI 글자 수 재조절(요약/확장) 기능
6. **문서 다운로드:** 완성된 자기소개서를 Word(.docx) 또는 PDF 파일로 즉시 다운로드
7. **히스토리 관리:** 과거에 작성한 자기소개서 내역 저장 및 다시 보기 (브라우저 LocalStorage 활용)

---

### 4. 기술 스택
| 구분 | 선택 기술 | 비고 |
| :--- | :--- | :--- |
| **Frontend Framework** | **Next.js (App Router)** | 빠른 SSR/SSG 및 API Route 내장으로 단일 프로젝트 구조화 |
| **Styling** | **Tailwind CSS** | 바이브코딩 최적화 반응형 UI 라이브러리 |
| **Data Storage** | **Browser LocalStorage** | 별도 DB 구축 없이 작성 상태, 임시 저장, 작성 히스토리 관리 |
| **AI Model** | **Google Gemini API** | **`gemini-3.8-flash`** (빠른 응답 속도 및 고성능 텍스트 생성) |
| **File Export** | **`docx`, `jspdf` / Browser Print** | 클라이언트 사이드 Word 및 PDF 파일 변환 |

6. 상세 기능 명세
입력 검증 (Validation):

Step 1의 회사명/직무, Step 2의 공고, Step 3의 경험(STAR 또는 파일 중 택 1)이 모두 입력되어야 [생성하기] 버튼 활성화

AI 프롬프트 연동 및 생성 프로세스:

사용자가 입력한 채용공고의 핵심 키워드와 STAR 경험을 조합하여 gemini-3.8-flash 모델에 구조화된 프롬프트 전송

문항별(지원동기, 직무역량 등)로 파싱된 결과 반환

실시간 텍스트 에디터 및 글자 수 카운터:

생성된 자소서는 사용자가 직접 수정(Textarea) 가능

실시간으로 공백 포함 / 공백 제외 글자 수 계산 로직 적용

'글자 수 늘리기/줄이기' 버튼 클릭 시 프롬프트를 통해 분량 자동 조절

다운로드 기능:

클라이언트 라이브러리(docx, jspdf)를 활용하여 수정 완료된 텍스트를 즉시 Word 또는 PDF 문서 파일로 변환하여 다운로드

히스토리 자동 저장:

생성 완료 시점의 입력 데이터와 결과물을 브라우저 localStorage에 자동 저장하여 우측 상단 히스토리 모달에서 언제든 재확인 및 불러오기 가능

Tailwind CSS 기반의 모던한 둥근 모서리 카드 UI (rounded-2xl, shadow-md)

8. 제약사항 (Constraints)
API Key 보안: Gemini API Key는 클라이언트 노출을 최소화하기 위해 Next.js API Routes(Server-side) 환경변수(.env.local)에서 안전하게 관리

파일 용량 제한: 업로드하는 채용공고 및 이력서 파일(PDF/TXT)은 최대 5MB 이하로 제한하며, 텍스트 파싱 실패 시 직접 입력으로 유도

데이터 저장 한계: 브라우저 localStorage의 용량 한계(약 5MB)를 고려하여 최근 작성 내역 최대 20개까지만 유지하도록 관리 (초과 시 오래된 항목 자동 삭제 또는 안내)

토큰 제한: gemini-3.8-flash 모델의 컨텍스트 윈도우 내에서 원활히 처리되도록 공고 및 경험 텍스트가 과도하게 길 경우 핵심 위주로 트리밍(Trimming) 처리
